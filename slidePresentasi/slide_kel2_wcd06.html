Website portofolio perusahaan yang menampilkan profil, layanan, pengalaman, proyek, sertifikasi, dan kontak dari profesional IT. Dilengkapi latar 3D interaktif (Three.js), responsif, dan mendukung pergantian bahasa (Indonesia/Inggris) secara dinamis.

🛠️ Teknologi & Tools Detail

Frontend Framework & Library

  • React 18.2.0 – Library utama untuk membangun UI komponen dengan hooks (useState, useEffect, useRef, useCallback, lazy, Suspense)

Styling & UI

  • CSS3 – Custom styling dengan efek glassmorphism (backdrop-filter: blur), gradient text, animasi keyframes, flexbox, dan grid
  • Font Awesome 6.0 – Ikon vektor (fas, fab, fa-*) untuk tombol, kartu, dan navigasi
  • Google Fonts (Space Grotesk) – Font utama yang memberikan kesan modern dan profesional

  • Three.js 0.152.0 – Membuat latar belakang 3D interaktif dengan sphere, partikel, orbit, dan efek fog

  • requestAnimationFrame – Digunakan untuk animasi smooth pada carousel 3D dan background Three.js

Layanan & API

  • EmailJS 3.11.0 – Mengirim email dari form kontak langsung dari client-side tanpa server

Development Tools

  • ESLint – Linter untuk menjaga kualitas kode

  • Netlify – Hosting dan deployment dengan continuous deployment dari GitHub

Kelayakan UI/UX

✅ Kelebihan UI/UX (Skor: 8.5/10)

  • Navigasi & Struktur: Fixed navbar dengan 8 menu utama, routing SPA yang mulus, serta active state pada link memudahkan orientasi pengguna.
  • Responsivitas & Desain Visual: Menggunakan clamp() untuk tipografi, media query ≤768px, grid auto-fit, serta efek glassmorphism (backdrop-filter: blur) yang memberikan kesan modern dan premium.
  • Interaktivitas 3D & Animasi: Background Three.js dengan partikel dan parallax, Carousel 3D dragable, Timeline Scroll Reveal, serta Flip Card sertifikasi yang membuat pengalaman browsing menjadi engaging.
  • Pengalaman Pengguna: Dukungan dua bahasa (ID/EN) dengan persistensi localStorage, serta fitur copy kontak satu klik untuk meningkatkan konversi.

⚠️ Saran Perbaikan (Prioritas)

  • Optimalisasi Performa (Tinggi): Beban rendering Three.js dengan 600 partikel + 500 bintang cukup berat untuk perangkat entry-level. Tambahkan opsi "Nonaktifkan Efek 3D" atau deteksi performa device secara otomatis.
  • Error Handling & Form (Sedang): Saat ini API gagal hanya menampilkan alert. Tambahkan retry mechanism dan integrasikan EmailJS dengan feedback visual (loading, sukses, error) yang lebih informatif untuk form kontak.
  • Aksesibilitas (Sedang): Meskipun sudah ada focus-visible dan keyboard event (Enter/Space), masih perlu dilengkapi aria-label pada tombol interaktif dan kartu untuk mendukung pembaca layar (screen reader).
Kesimpulan UI/UX: Desain modern, interaktivitas tinggi, dan responsivitas yang solid. Dengan perbaikan pada performa, error handling, dan aksesibilitas, website ini akan menjadi platform portofolio perusahaan IT yang sempurna. 🚀

Kesimpulan & Rekomendasi

✨ Keunggulan Proyek: Portofolio modern dengan 3D interactivity, bilingual, responsif, dan mudah di-maintain.

⏳ Mengapa Muncul Icon Loading Saat Navigasi?

Pada website yang di-deploy di Netlify, beberapa halaman menampilkan ikon loading saat diakses. Hal ini disebabkan oleh teknik optimasi performa yang diterapkan pada aplikasi React:

  • Lazy Loading (Code Splitting): Aplikasi menggunakan React.lazy() dan Suspense untuk memuat komponen secara lazy. Setiap halaman (Home, Tentang, Keahlian, dll.) dipisahkan menjadi chunk JavaScript tersendiri yang hanya dimuat saat halaman tersebut diakses untuk pertama kali.
  • Manfaat: Mempercepat waktu muat awal (initial load) karena hanya kode untuk halaman pertama yang diunduh. Ini mengurangi bundle size dan meningkatkan performa, terutama pada koneksi lambat.
  • Fallback Loading: Komponen Suspense menampilkan spinner/loading sebagai penanda bahwa konten sedang dimuat. Ini memberikan feedback visual yang baik kepada pengguna.
  • Faktor Lain: Selain lazy loading, beberapa fitur seperti Three.js (background 3D) dan API eksternal (harga pasar, berita) juga membutuhkan waktu muat tambahan, yang dapat memicu indikator loading.
Tips: Loading icon hanya muncul saat pertama kali mengunjungi halaman. Setelah halaman dimuat, navigasi berikutnya akan terasa lebih cepat karena kode telah tersimpan di cache browser.

📌 Rekomendasi Pengembangan Lanjutan

  • Lazy loading untuk Three.js agar performa lebih baik di perangkat rendah.
  • Tambah modal detail proyek (mengganti alert).
  • Implementasi aksesibilitas penuh (role, aria-label).
  • Integrasi form kontak dengan layanan email.
